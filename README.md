# mumble-bote

Простой бот для Mumble. Умеет ходить по ссылкам в чате и присылать превью, в том числе из Youtube-роликов. Умеет примитивное хистори на 10 постов. Умеет решать важные жизненные задачи. При входе выключает себе динамики и микрофон, так что никого не подслушивает.

# Инсталляция

Для дебиан-подобных дистрибутивов надо поставить немного зависимостей, здесь как отдельные утилиты, так и перловые зависимости, вынесенные в отдельные пакеты:
```
apt-get install imagemagick imagemagick-common ddate wget curl
apt-get install libdigest-sha-perl libcryptx-perl libfile-slurp-perl libgoogle-protocolbuffers-perl libhtml-parser-perl libio-socket-ssl-perl libjson-perl libwww-perl liburi-perl
```
В зависимости входит и [https://github.com/lwthiker/curl-impersonate](https://github.com/lwthiker/curl-impersonate), который собирается ручками. Но если оно не нужно, то можно и без него, просто замените на обычный `curl`.

Если в вашем дистрибутиве нету всех перловых зависимостей, то недостающие можно поставить из CPAN:
```
cpan -i Digest::SHA1
cpan -i File::Slurp
```
Для тестирования, что все установлено хорошо, можно запустить `./deps_test.sh`, оно не должно сыпать ошибками

Чтобы сервис стартовал автоматически, можно воспользоваться `systemd` и поместить прилагаемый файл `bote.service` в `/etc/systemd/system`

# Настройка бота

Открываем файл `mumble_bote.pl` и правим в его начале некоторые переменные:
```
my $botName='Bote';
my $botServer='mumble.example.com:64738';
my $useDebug=0;
```
Других настроек у бота нет, но вроде бы и не нужно более. Пути к сертификатам можно оставить дефолтные.

Имя боту задается как значение переменной и может быть динамическим, к примеру:
```
my $useRandomNameSuffix=1;
my $botName=$ARGV[0]||'Bote'.($useRandomNameSuffix?" ".int(rand()*10000):"");
```
Такое имя может быть задано из командной строки, а если в ней ничего не указано, то будет использовано слово "Bote" и если определена переменная `$useRandomNameSuffix`, то к имени будет добавлено случайное цифровое значение. Полезно для запуска множества ботов из одной директории.

Бот автоматически сгенерирует себе сертификаты и аватарку. При первом запуске он скачает себе `Mumble.proto` с гитхаба и из него сделает себе модуль.

# Команды бота

Вся логика работы бота вынесена в отдельный файл `mumble_bote_logic.pl`, который можно править без перезагрузки бота. Будте с этим осторожны, так как если логика будет неработоспособной, то бот не сможет более ничего выполнять и его надо будет перезапускать с нуля.

Если появляются сообщения вида `STUB IS USED!!!`, то проверьте наличие и исправность файла логики.

Поддерживается простая команда `ping`, в ответ на которую бот выдаст простой ответ `pong`.

Если бот увидит ссылку, то он по ней перейдет (используя curl_impersonate), поищет в ней заголовки и по возможности все это репостнет в чат.

При входе на сервер нового пользователя, бот в личечку сообщит этому пользователю последние 10 сообщений и список пользователей за последние сутки.

# Решение важных жизненных задач

Если написать `Что делать?` и в следующих строках перечислить вариванты ответа, то груз ответственности за ваши жизненные решения, на себя может взять бот:
```
[19:53:15] Для Root: Что делать?
Поесть
Поспать
Погулять

[19:53:16] (Канал) Bote: username: вам следует:
Поспать - 110%
Погулять - 110%
Поесть - 61%
```
